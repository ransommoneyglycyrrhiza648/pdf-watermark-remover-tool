## 💡 What is a Watermark?

A watermark is text or an image placed **behind** the main content or **on top** of it. Common examples include:

- *CONFIDENTIAL* stamped across pages
- A company logo in the background
- An author's name at the bottom corner
- "Preview" or "Sample" text on documents

This tool strips those elements away while keeping everything else perfectly intact.
